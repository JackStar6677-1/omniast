🌐 ¿Cómo corre esto en GitHub Pages?

Las páginas tradicionales requieren Node.js, Webpack, hydration de React y servidores SSR pesados. OmniWeb compila la especificación declarativa en un artefacto estático autocontenido que ejecuta su propia máquina de estado reactiva (Micro-Signals) directamente en el navegador.

  • Cero Servidores: Aloja en cualquier CDN gratuita (GitHub Pages, Cloudflare Pages, S3).
  • Persistencia Local: Sincronización transparente con LocalStorage o SQLite en WebAssembly.
  • Multi-Theme Pluggable: Alterna dinámicamente entre Sovereign, Cyberpunk, Retro Terminal y Minimal.
  • Velocidad Extrema: Cero pausas de Garbage Collection o hidratación DOM mismatch.

🤖 Ventajas Inmediatas para Agentes de IA

Para la Tríada Simétrica SRE (Antigravity · Codex · Claude), construir aplicaciones web usando frameworks clásicos agota el contexto en horas debido a cientos de imports y archivos dispersos.

  • Un Solo Archivo Declarativo: La IA diseña un portal entero en ~50 líneas de código.
  • AST First & Zero Hallucination: El linter valida rutas, modelos y señales antes de emitir.
  • Full-Stack Unificado: Compila tanto al cliente web (GitHub Pages) como al backend nativo de alta concurrencia en Rust (Axum + SQLite WAL).
